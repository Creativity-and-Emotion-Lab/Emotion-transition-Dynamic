# Analysis Code

This repository contains the analysis code used to compute emotion dynamic indices and conduct subsequent statistical analyses.

## Software

Markov transition matrices, transition probabilities, and PageRank indices were computed in MATLAB R2022a (MathWorks, Natick, MA, USA).

Subsequent statistical analyses were conducted in Python 3.12 using SciPy, statsmodels, and custom Python scripts.

## MATLAB Analysis

The MATLAB scripts were used to compute individual-level Markov chain indices based on ecological momentary assessment (EMA) data, including:

* Markov transition matrices
* Transition probabilities
* PageRank indices
* Transition density

## Python Analysis

The Python scripts were used for subsequent statistical analyses, including correlation analyses, multiple-comparison correction, and sensitivity analyses.

## Data Availability

Data associated with this study are organized into the following categories:

- **Numerical data underlying figures and tables:** The numerical data underlying the figures and tables reported in the manuscript are publicly available in the `numerical_data_underlying_figures_tables` folder.

- **Processed anonymized data:** The processed and anonymized datasets necessary to reproduce the main analyses and findings are publicly available in the `processed anonymized data` folder.

- **Time-series data:** The time-series data used in the relevant analyses are publicly available in the `time series` folder.

- **Raw neuroimaging data:** The raw neuroimaging data are not included in this public repository because of their large file size. These data are available from the corresponding author upon reasonable request.
